Research

Teams now put large language models in their code review pipelines. The developer whose code is being checked also writes its comments, so a comment like "validated upstream, safe" becomes an attack. My experiments measure which of these comments work, why, and what removes the risk.

Across 780 trials, the strongest comments claimed authority over the code, and a bare statement of the author's confidence, which verifies nothing, worked nearly as well. Removing comments before analysis restored detection completely in the setting I tested.
