One comment can fool an AI code reviewer

A misleading comment, not a code change, drops how often an LLM catches a real vulnerability. Stripping comments before review brings it all the way back.
4 open code models 480 reviews per condition detection rate on vulnerable code
baseline
No comment
code reviewed as written
90.0%
attack
Misleading comment added
a comment claiming the code is safe
75.2%
defense
Comments stripped
remove comments, then review
90.0%
The model was reading the comment, not just the code. A 15-point drop from text that changes nothing about what the program does. The fix is cheap: strip comments before the model reviews.
